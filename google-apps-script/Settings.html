Configuración de ChatKit

ℹ️ Esta configuración se guarda directamente en el archivo Code.gs. Necesitas editar el código para cambiar estas credenciales.
Obtén tu API key en platform.openai.com/api-keys
Crea un workflow en Agent Builder y copia el ID

📋 Instrucciones de configuración:

  1. Haz clic en "Abrir Editor de Script" arriba
  2. En el archivo Code.gs, encuentra la sección CONFIG
  3. Reemplaza 'tu-api-key-aqui' con tu API key de OpenAI
  4. Reemplaza 'tu-workflow-id-aqui' con tu Workflow ID de Agent Builder
  5. Guarda el archivo (Ctrl+S o Cmd+S)
  6. Cierra este diálogo y vuelve a abrir ChatKit desde el menú
